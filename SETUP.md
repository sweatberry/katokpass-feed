# Сборщик рейсов KatokPass: как подключить

Сборщик каждые 15 минут читает Telegram-канал Step to Travel от имени вашего аккаунта, разбирает посты и сохраняет рейсы в файл `docs/deals.json`. Приложение скачивает этот файл. Рейсы, опубликованные больше 24 часов назад, в файл не попадают, и приложение тоже их скрывает.

Настройка занимает около 20 минут и делается один раз.

---

## Шаг 1. Ключи Telegram

1. Откройте https://my.telegram.org и войдите по номеру телефона, на котором вы подписаны на канал.
2. Нажмите **API development tools**.
3. Заполните форму: App title — `KatokPass`, Short name — `katokpass`, Platform — `Other`.
4. Сохраните два значения: **api_id** (число) и **api_hash** (длинная строка).

## Шаг 2. Строка входа

**Как открыть Терминал:** нажмите **Cmd + Пробел**, наберите `Терминал` (или `Terminal`) и нажмите Enter. Откроется окно с текстом — туда вставляются команды.

Скопируйте команды ниже **по одной строке**, вставьте в Терминал (Cmd + V) и нажмите Enter. Дождитесь, пока закончит, и переходите к следующей:

```
cd ~/Documents/KatokPass/feed-collector
python3 -m venv .venv
source .venv/bin/activate
pip install -r requirements.txt
python collector/login_once.py
```

- Если Mac спросит «Терминал хочет получить доступ к папке „Документы“» — нажмите **Разрешить**.
- Если после `python3` появится окно «Установить инструменты разработчика» — нажмите **Установить**, дождитесь конца и повторите команду.
- Когда пароль или код вводятся, символы могут не отображаться — это нормально.

Последняя команда спросит `api_id`, `api_hash`, номер телефона (в формате +7…) и код, который придёт в Telegram. В конце она напечатает длинную строку. Скопируйте её целиком: это **TG_SESSION**.

**Если код в Telegram не приходит** — войдите по QR-коду. В том же Терминале (Control + C, чтобы остановить предыдущую команду):

```
pip install -r requirements.txt
python collector/login_qr.py
```

Введите `api_id` и `api_hash` — на экране откроется QR-код. На телефоне: **Telegram → Настройки → Устройства → Подключить устройство** и наведите камеру на код. Если у аккаунта есть облачный пароль, Терминал его спросит.

> ⚠️ Эта строка даёт полный доступ к вашему Telegram. Не пересылайте её никому (и мне в чат тоже), не вставляйте в код — только в секрет на GitHub. Надёжнее завести для сборщика отдельный аккаунт, подписанный только на нужные каналы.

## Шаг 3. Репозиторий на GitHub

1. Зарегистрируйтесь на https://github.com, если аккаунта ещё нет.
2. Нажмите **New repository**, назовите его `katokpass-feed` и выберите **Public**.
   Для публичного репозитория запуски по расписанию бесплатны без ограничений. Файл с рейсами будет виден всем, секреты — нет.
3. Нажмите **uploading an existing file** (или **Add file → Upload files**) и перетащите из папки `feed-collector` всё, кроме файла `workflow-collect.yml`: папки `collector`, `docs`, `tests` и файлы `requirements.txt`, `sources.json`, `SETUP.md`. Нажмите **Commit changes**.
4. Создайте файл расписания: **Add file → Create new file**. В поле имени введите ровно
   `.github/workflows/collect.yml`
   и вставьте в него всё содержимое файла `workflow-collect.yml` (откройте его в TextEdit, Cmd + A, Cmd + C). Нажмите **Commit changes**.

## Шаг 4. Секреты

В репозитории откройте **Settings → Secrets and variables → Actions → New repository secret** и добавьте три секрета:

| Имя | Значение |
|---|---|
| `TG_API_ID` | api_id из шага 1 |
| `TG_API_HASH` | api_hash из шага 1 |
| `TG_SESSION` | строка из шага 2 |

## Шаг 5. Первый запуск

1. Откройте вкладку **Actions** и включите workflows, если GitHub попросит.
2. Выберите **Сбор рейсов** и нажмите **Run workflow**.
3. Через минуту должна появиться зелёная галочка, а в `docs/deals.json` — рейсы.
   Если галочка красная, откройте запуск и посмотрите, что написано в шаге «Прочитать канал».

## Шаг 6. Подключить приложение

В Xcode откройте `KatokPass/Model/Models.swift` и в строке `feedURLString` замените `USERNAME` на своё имя пользователя GitHub:

```
https://raw.githubusercontent.com/ВАШ_ЛОГИН/katokpass-feed/main/docs/deals.json
```

Нажмите Cmd + R. Надпись «Демо-рейсы» пропадёт, и в ленте появятся рейсы из канала.

## Как менять настройки без обновления приложения

Все настройки лежат в файле **`sources.json`** в репозитории. Откройте его на GitHub, нажмите ✏️, внесите правки и нажмите **Commit changes**. При следующем запуске сборщика, то есть в течение 15 минут, изменения появятся у всех пользователей.

- **Сменить канал:** замените ссылку в `telegram`. Аккаунт из шага 2 должен быть подписан на новый канал.
- **Добавить ещё один канал:** добавьте в `sources` ещё один блок `{ "name": …, "telegram": …, "enabled": true }`.
- **Временно отключить канал:** поставьте `"enabled": false`.
- **Сменить номер для заявок:** поменяйте `whatsApp`, только цифры.
- **Сменить срок показа:** поменяйте `ttlHours` (сейчас 24).

Переустанавливать приложение нужно только при смене адреса самого файла (`feedURLString`).

## Если рейсы не распознаются

Разборщик понимает маршруты вида «Алматы – Анталия», «ALA-AYT» и «Из Астаны в Хургаду», даты вида «17.09», «17 сентября» и «23-28.09», а также цены в тенге. Город, которого нет в справочнике, добавьте одной строкой в `collector/places.py`.

Если пост написан в необычном формате, пришлите его текст: разборщик подстроим под него. Тесты лежат в `tests/test_parser.py`.
